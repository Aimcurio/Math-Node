# Agents and Skills Policy

## Boundary
Agents develop, investigate, verify, and govern capability. They do not sit on the normal deterministic Math Runtime path for already-known operations.

## Agents 001–007
Existing numbered agents retain their current conceptual responsibilities pending inspect-first audit. New functionality must not be disguised as additional numbered agents when it is better represented as a skill, service, verifier, or engine.

## Five Agent-Plane skills
The following are skills/capabilities, not Agents 008–012:
1. `agentic-math-rag` — retrieval for mathematical capability development.
2. `knowledge-graph-rag` — graph-aware evidence and dependency retrieval.
3. `corrective-rag` — detect weak retrieval/evidence and repair the retrieval path.
4. `self-improving-skill-optimizer` — propose measured skill improvements; cannot self-promote changes without verification.
5. `trust-gate-audit-team` — independent trust, evidence, provenance, and promotion review.

## Communication policy
Machine-to-machine messages should be typed, versioned artifacts with explicit contracts. Natural language is allowed when it is itself the task material or when a model requires it internally, but it must not substitute for a structured trust boundary.

Agents may coordinate through parallel work, pipelines, planner/executor delegation, supervisor/worker delegation, shared blackboards, critique/revision, consensus, or event-driven handoffs. The orchestrator selects a topology from policy based on dependencies, risk, latency, and verification needs.

## Human oversight
Any decision requiring HITL must be translated into clear natural language and, where useful, a high-information visual generated from the same verified artifacts. The human must be able to inspect evidence, provenance, uncertainty, alternatives, and consequences before approval.

## Promotion rule
No agent or skill can declare its own consequential output trusted. Promotion requires the applicable independent verification contract. Self-improvement produces a candidate revision, not an automatically trusted revision.
